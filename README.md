# Mob Control: StarCraft (PWA) v0.4.0

Three.js 기반 3D 모브 컨트롤 스타일 모바일 세로형 게임입니다.

## 플레이 방법
- 화면을 좌우로 드래그하면 발사대가 움직이고, 유닛이 자동으로 계속 나옵니다. (PC는 방향키 가능)
- **게이트**를 통과하면 유닛이 늘어납니다. `+N`은 유닛 1기당 N기 추가, `×N`은 N배입니다.
- 왼쪽 계단의 `+1` 게이트 4개는 연속으로 통과하면 2배씩 늘어나는 지름길입니다.
- 주황 **터렛**(숫자)에 유닛을 갖다 넣어 숫자를 0으로 만들면 아군 포탑이 18초간 자동 사격합니다.
- 적 군중을 뚫고 **보스(3·6·9·12레벨…)**와 **타워**의 HP를 0으로 만들면 승리합니다.
- 적이 발사대 라인에 닿으면 기지 HP가 깎이고, 0이 되면 패배합니다.

## 스타크래프트 테마 (v0.4.0: 일러스트 스프라이트 적용)
- 레벨마다 **테란 사령부 → 프로토스 신전 광장 → 저그 군락** 테마가 순환하며, 시안 이미지로 만든 배경/바닥 텍스처가 적용됩니다.
- 상단 바는 `MINERALS / VESPENE`(저그는 `CREEP / BIOMASS`)와 `MISSION TIME`(저그는 `INFESTATION TIME`)을 표시합니다.
- 해병·드라군은 저그 군락(Hive)과, 히드라리스크는 테란 사령부와 싸우며 보스도 종족에 맞게 바뀝니다.
- 유닛/보스/타워는 `assets/` 의 투명 PNG 일러스트(빌보드)입니다. 같은 파일명으로 교체 가능, `?3d=1` 로 열면 기존 3D 도형 모드.

## 유닛
| 유닛 | 특징 |
|---|---|
| 해병 (테란) | 균형형 |
| 드라군 (프로토스) | 생산은 느리지만 HP 2, 공격력 2 |
| 히드라리스크 (저그) | 빠른 생산, 빠른 이동 |

승리/패배 보상으로 미네랄을 얻어 유닛 승급, 수입 증가, 기지 강화를 합니다.

## 이어하기
진행 상황은 2초마다 localStorage에 저장되고, 앱이 백그라운드로 가면 자동 일시정지됩니다. 다시 열면 같은 전투 상태로 복원되어 "계속하기"로 이어집니다.

## GitHub Pages 배포
1. 이 폴더의 `index.html, game.js, sw.js, manifest.webmanifest, icons/, assets/`를 저장소 루트에 올립니다. (`src/`는 소스, 올려도 무방)
2. Settings → Pages → `main` / root 저장.
3. `https://<계정>.github.io/<저장소>/` 접속 → 홈 화면에 추가.

## 소스 수정 후 빌드
```
npm install
npm run build     # src/main.js → game.js (three.js 포함 번들)
```
버전을 올릴 때는 `src/main.js`와 `sw.js`의 `VERSION`을 같이 올리세요.
