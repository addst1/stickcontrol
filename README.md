# Stickman Count v1.3.0

Count Masters 스타일 스틱맨 군중 러너 (Three.js, 모바일 세로 PWA)

## 규칙
- 화면을 드래그하면 군중이 좌우로 움직이고, 자동으로 전진합니다. 터치하면 시작.
- **게이트** `+N` `×N` 은 인원 증가, `-N` `÷N` 은 감소. 군중 중심이 지나는 쪽이 적용됩니다.
- **톱날 / 해머 / 가시 / 회전 가시봉 / 붉은 벽 / 압착기**에 닿은 스틱맨은 죽습니다. **좁은 다리**(양옆 가시 구덩이)에서는 군중이 길게 모입니다.
- **노란 경사로**를 오르면 고지대 구간이 나옵니다. **초록 버튼**을 밟으면 +N 합류.
- **적 군중**(빨강/주황 궁수)과 **궁수 탑**은 붉은 경계 안에 들어가면 맞붙습니다. 탑은 접근하는 동안 화살을 쏩니다. 부딪히면 1:1로 맞붙어 숫자가 같이 줄어듭니다. 이기면 남은 인원으로 계속 달립니다.
- **회색 스틱맨**은 합류하는 중립 군중(+N), 금화는 코인으로 저장됩니다.
- 보스 직전 **TAP TO CHOOSE** 룰렛에서 타이밍에 맞춰 터치하면 보너스 인원을 받습니다.
- **보스**(투구+검)를 쓰러뜨리면 **계단**을 오르며 단계마다 인원이 줄고, 도달한 단계의 배수(x1.2 ~ x5.8)만큼 코인을 받습니다. 인원이 0이 되면 실패입니다.
- 시작 화면 하단 카드로 **Start Units / Income** 을 코인으로 업그레이드합니다.
- 레벨은 번호로 결정되는 고정 코스입니다. 테마(보라 크리스탈/핑크 바다/노을)는 레벨마다 순환합니다.

## PC에서 실행
`index.html` 을 더블클릭해도 바로 실행됩니다(서버 불필요). 마우스 드래그 또는 `A/D`·방향키로 이동, `Space`로 시작/룰렛 선택. 서비스워커(오프라인 설치)는 GitHub Pages 같은 https 환경에서만 동작합니다.

## 스킨
시작 화면 우측 SKINS 에서 코인으로 구매·장착(9종). 레벨을 클리어할 때마다 스킨 진행도가 20% 오르고 100%가 되면 다음 스킨이 무료로 열립니다.

## 이어하기
2초마다 localStorage에 저장하고, 앱을 내리면 자동 일시정지됩니다. 다시 열면 같은 위치·인원·적 상태로 "계속하기" 합니다.

## 모드 추가 (확장)
`src/main.js` 의 `MODES` 레지스트리에 `{ name, gen(level, startUnits) }` 를 추가하면 새 코스 규칙을 넣을 수 있습니다. (현재 `classic` 1종)

## 배포 (GitHub Pages)
`index.html, game.js, sw.js, manifest.webmanifest, icons/` 를 저장소 루트에 올리고 Settings → Pages → `main` / root.
(`file://` 로 직접 열면 서비스워커가 동작하지 않으니 서버/Pages로 확인하세요.)

## 빌드
```
npm install
npm run build   # src/main.js → game.js
```
버전을 올릴 때는 `src/main.js` 와 `sw.js` 의 `VERSION` 을 같이 올리세요.
